3. รูปแบบการใช้งาน Admin Content Manager (3 ทางเลือก)

แนวทางที่ 1: Built-in Dark Mode Content Manager (พอร์ต 9091)

สร้างขึ้นโดยถอดแบบหน้าตา Strapi 5 Content Manager (ตามภาพที่ผู้ใช้ส่งมา) ครบถ้วนทั้งโทนสี Dark Theme, แถบไอคอนซ้ายสุด, รายการ Collection Types, แถบค้นหา, ฟิลเตอร์, ป้ายสถานะสี, และปุ่ม "+ Create new entry"

  • URL เข้าใช้งาน: http://localhost:9091/admin
  • ไฟล์ต้นทาง: public/admin/index.html รันผ่าน Express Server ทันทีเมื่อเปิดคำสั่ง npm run dev
  • ฟังก์ชันที่รองรับ: สลับดู Collection Types ทั้ง 6 ชนิด, ฟอร์ม Modal เพิ่มข้อมูลใหม่, ค้นหาแบบ Real-time, และลบข้อมูล

แนวทางที่ 2: Supabase Studio Table Editor (บนคลาวด์)

สำหรับทีมที่ต้องการเชื่อมต่อกับฐานข้อมูล Supabase PostgreSQL โดยตรง Supabase มีระบบ Table Editor ที่มีคุณสมบัติเช่นเดียวกับ Strapi Content Manager:

  • เข้าถึงได้ที่: Supabase Dashboard -> Table Editor
  • แสดงตาราง categories, shelters, pets, adoption_applications, pet_inquiries, profiles
  • มีปุ่ม Insert Row, รองรับการอัปโหลดไฟล์ภาพเข้า Storage Bucket, และระบบค้นหากรองข้อมูลแบบ Multi-column

แนวทางที่ 3: ติดตั้งบน Strapi 5 Headless CMS โดยตรง (พอร์ต 1337)

หากต้องการรัน Strapi 5 ต่อไปตามหน้าจอเดิม สามารถสร้าง Collection Types ด้วย 4 ขั้นตอน:

  1. เปิดหน้า Strapi http://localhost:1337/admin -> เข้าเมนู Content-Type Builder
  2. คลิก "+ Create new collection type" ตั้งชื่อ Display Name: Category, Shelter, Pet, Adoption Application, Pet Comment
  3. เพิ่ม Fields ตามตารางในข้อ 1 แล้วคลิก Save
  4. ระบบ Strapi จะคอมไพล์และสร้างหน้าจอ Content Manager ให้ใช้งานตามภาพของท่านทันที

4. สรุปคำแนะนำในการแบ่งงานทีม 3 คนสำหรับ Content Module

สมาชิก หน้าที่ต่อ Content ผลงานที่ต้องส่งมอบในส่วน Content
คนที่ 1 (DB Lead) สร้างตารางและ Seed ข้อมูล Content สคริปต์ schema.sql และ seed.sql ครอบคลุมทั้ง 6 Entities พร้อมข้อมูลตัวอย่างสัตว์เลี้ยง 5 ตัว
คนที่ 2 (Auth Lead) ควบคุมสิทธิ์เข้าถึง Content กำหนด RLS Policies ว่าใครมีสิทธิ์เพิ่ม ลบ หรือแก้ไขสัตว์และใบสมัคร (Admin/Staff vs Adopter)
คนที่ 3 (API Lead) เชื่อมต่อ Content กับ REST API ทดสอบยิง CRUD Endpoints สำหรับทั้ง 6 Content Types ผ่านไฟล์ api.http.simple ให้สมบูรณ์
