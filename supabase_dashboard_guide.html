Supabase Studio vs Strapi Dashboard

คู่มือระบบ Dashboard ของ Supabase
(Supabase Studio & Table Editor)

การใช้งาน Dashboard จัดการ Content แบบเดียวกับ Strapi Content Manager ในระบบ Pet Adoption
ชื่อระบบ Dashboard Supabase Studio (Table Editor)
ระบบที่เปรียบเทียบ Strapi 5 (Content Manager)
ช่องทางเข้าใช้งาน Supabase Cloud / Local Studio (Port 54323)
หน้าที่หลัก จัดการตาราง, Insert Row, จัดการรูปภาพ & User

🎯 คำตอบสำคัญ: Supabase มี Dashboard เหมือน Strapi หรือไม่?

มีแน่นอน 100%! Supabase มีระบบควบคุมบริหารหลังบ้านในตัวที่ชื่อว่า "Supabase Studio" ซึ่งมีฟังก์ชันครบถ้วนและทันสมัยไม่แพ้ Strapi โดยเฉพาะเมนู "Table Editor" ที่ทำหน้าที่เป็น Content Manager แสดงรายการตารางทั้งหมด มีปุ่ม Insert Row (เหมือน + Create new entry), ระบบค้นหา, กรองข้อมูล, อัปโหลดรูปภาพเข้า Storage และดูความสัมพันธ์ระหว่างตารางได้สดๆ แบบ Real-time

📌 เมนูใน Supabase Studio ที่เทียบเท่า Strapi

  • Table Editor = Strapi Content Manager (เพิ่ม/ลบ/แก้ไขข้อมูลสัตว์เลี้ยง, หมวดหมู่, ใบสมัคร)
  • Storage = Strapi Media Library (อัปโหลดและจัดการรูปภาพสัตว์เลี้ยง)
  • Authentication = Strapi Users & Permissions (จัดการผู้ใช้และกำหนดสิทธิ์)
  • SQL Editor = ตัวจัดการฐานข้อมูลระดับสูง (รัน Script SQL & Migrations)
จัดทำโดย: ทีมพัฒนาประจำโครงการ Pet Adoption API | เอกสารคู่มือ Dashboard ฉบับแยก

1. ตารางเปรียบเทียบเมนู Dashboard ระหว่าง Supabase กับ Strapi

ฟังก์ชันการทำงาน Strapi Dashboard (ภาพที่ส่งมา) Supabase Studio (Dashboard ในตัว)
การจัดการ Content / ตาราง Content Manager
มีเมนู Collection Types ด้านซ้าย (Category, Ticket ฯลฯ)		 Table Editor
มีเมนูด้านซ้ายแสดงตารางทั้งหมด (categories, pets, shelters ฯลฯ)
ปุ่มเพิ่มข้อมูลใหม่ ปุ่มสีน้ำเงิน + Create new entry ปุ่มสีเขียว + Insert row (เปิดฟอร์มกรอกข้อมูลทันที)
การจัดการรูปภาพ/ไฟล์ Media Library
เก็บไฟล์ในเซิร์ฟเวอร์หรือ Cloudinary		 Storage
มี Buckets (เช่น pet-images) พร้อม CDN URL ในตัว
การจัดการผู้ใช้และสิทธิ์ Users & Permissions Plugin
แบ่ง Role: Authenticated, Public		 Authentication & Policies
จัดการ User รายคน พร้อมกำหนด Row Level Security (RLS)
การแสดงผลข้อมูล รูปแบบ Table List พร้อม Filter & Search รูปแบบ Spreadsheet/Grid View (แก้ไขได้สดๆ ในช่องตาราง)
การดูความสัมพันธ์ (Relations) คลิกดูรายการเชื่อมโยง เช่น 1 item ▾ มีปุ่มลิงก์ Foreign Key ไปยังตารางที่เกี่ยวข้องได้ทันที

3. ช่องทางการเข้าใช้งาน Supabase Dashboard (2 วิธี)

วิธีที่ 1: ใช้ Supabase Cloud Dashboard (แนะนำที่สุด - สะดวกและเร็ว)

Supabase มี Dashboard ให้ใช้งานฟรีบนคลาวด์ ไม่ต้องเปลืองทรัพยากรเครื่องคอมพิวเตอร์:

  1. เข้าไปที่ https://supabase.com/dashboard แล้วล็อกอินด้วย GitHub
  2. เลือกโปรเจกต์ของคุณ (เช่น pet-adoption-api)
  3. คลิกเมนู "Table Editor" ทางด้านซ้าย จะพบตารางทั้งหมดที่รันจากไฟล์ schema.sql
  4. สามารถคลิกปุ่ม "+ Insert row" เพื่อเพิ่มข้อมูลสัตว์เลี้ยงตัวใหม่ หรือแก้ไขข้อมูลได้ทันที

วิธีที่ 2: รัน Supabase Studio บนเครื่องของตนเอง (Local Docker พอร์ต 54323)

หากต้องการรัน Dashboard ในเครื่องแบบเดียวกับที่ Strapi รันบนพอร์ต 1337:

# 1. ติดตั้ง Supabase CLI (หากยังไม่มี) npm install -g supabase # 2. เริ่มการทำงานของระบบ Supabase Local Studio npx supabase start
  • เมื่อคำสั่งรันเสร็จ Supabase จะเปิด Dashboard บนเครื่องที่: http://localhost:54323
  • คุณจะได้หน้าจอ **Supabase Studio** ในเครื่องตัวเอง สามารถจัดการ Content ทุกอย่างได้แบบ Offline 100%

4. สรุปความคุ้มค่าและข้อได้เปรียบของ Supabase Studio

คุณสมบัติ Strapi Content Manager Supabase Studio (Dashboard)
การจัดการฐานข้อมูล ต้องสร้างผ่าน UI ของ Strapi เท่านั้น รองรับทั้ง UI กดเพิ่มแถว และ SQL Editor
ความเร็วในการแก้ไขข้อมูล ต้องกดเข้าไปทีละหน้าเพื่อแก้ไข Inline Editing ดับเบิลคลิกแก้ในเซลล์ตารางได้เลย
ระบบความปลอดภัย (Security) จัดการสิทธิ์ผ่าน Controller / Policies โค้ด Node.js PostgreSQL Row Level Security (RLS) ปลอดภัยระดับชั้น Database
การขยายขนาด (Scalability) ผูกติดกับ Node.js Instance ใช้พลังของ PostgreSQL แท้ รองรับข้อมูลมหาศาลได้อย่างเสถียร
